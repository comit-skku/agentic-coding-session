# CoMit Website

## 프로젝트 목적과 이번 범위

성균관대학교 중앙동아리 CoMit을 소개하고, 부원들이 학기별 스터디를 찾고 함께할 수 있는 웹사이트를 만드는 것이 프로젝트의 목적입니다. 기존 기획에는 학교 계정 로그인, 스터디 개설 및 참여가 포함되어 있습니다.

현재 저장소에서 확인되는 범위는 별도 빌드 도구나 프레임워크 없이 브라우저에 표시하는 단일 정적 페이지입니다. `index.html`은 화면 구조, `style.css`는 스타일, `script.js`는 검색·카테고리 필터와 테마 전환 동작을 담당합니다. 페이지에는 동아리 소개 문구와 제목·카테고리로 필터링할 수 있는 이번 학기 스터디 예시 한 건이 들어 있습니다.

## 현재 동작하는 기능과 아직 구현되지 않은 기능

### 현재 동작하는 기능

- CoMit 소개 문구와 스터디 섹션을 표시합니다.
- 예시 스터디의 카테고리, 주제, 설명, 모임 시간, 장소, 기간, 모집 상태 및 예시 인원을 표시합니다.
- 제목 검색과 카테고리 선택을 함께 적용해 스터디 카드를 필터링하며, 결과가 없을 때 안내 문구를 표시합니다. 검색어가 비어 있고 카테고리가 `전체`이면 전체 목록을 표시합니다.
- 카테고리 선택지는 `기초 언어`, `웹/앱`, `AI`, `CS 기초`, `CS 심화`, `대회/공모전`, `자격증`이며, 현재 예시 스터디는 `웹/앱`으로 지정되어 있습니다.
- 상단 메뉴와 브랜드 링크로 페이지 내 `#about`, `#studies`, `#home` 위치로 이동합니다.
- 화면 너비가 좁을 때 카드와 메뉴 배치를 조정하는 CSS가 있습니다.

### 아직 구현되지 않은 기능

- 학교 계정 로그인 및 사용자 관리
- 스터디 목록의 서버 연동 또는 학기별 데이터 갱신
- 부원의 스터디 개설, 편집, 삭제 및 참여
- 모집 인원이나 상태의 실시간 갱신

## 실행·검증의 전제조건, 정확한 명령, 정상 기준

### 전제조건

- `index.html`을 열 수 있는 웹 브라우저가 필요합니다.
- 별도 패키지 설치나 빌드 과정은 확인되지 않았습니다.
- 자동화 테스트 또는 린트 설정은 저장소에서 확인되지 않았습니다.

### 실행

저장소 루트에서 PowerShell을 열고 아래 명령을 실행하면 기본 브라우저에서 페이지를 엽니다.

```powershell
Start-Process .\index.html
```

또는 파일 탐색기에서 `index.html`을 브라우저로 열 수 있습니다.

### 수동 확인 기준

브라우저에서 CoMit 제목과 소개 문구, `이번 학기 스터디` 제목, `웹 개발 입문 스터디` 카드가 보이면 페이지 표시가 정상입니다. 카드에 `웹/앱` 카테고리와 `프론트엔드` 주제, `모집 중`, `4 / 8명`, 모임 시간·장소·기간이 표시되는지 확인합니다. 카테고리 `전체`와 `웹/앱`에서 카드가 보이고, 다른 카테고리에서는 숨겨지는지 확인합니다. 제목 일부를 검색해 해당 카드가 표시되는지, 검색어를 지우면 목록이 복원되는지, 제목 검색과 카테고리 선택을 함께 사용해 두 조건에 모두 맞는 카드만 보이는지 확인합니다. 일치하지 않는 조건에서는 `검색 결과가 없습니다`가 표시되고 조건을 되돌리면 사라져야 합니다. 필터 사용 후 카드의 상세 보기와 다크 모드가 계속 동작하는지, 좁은 화면에서 필터를 사용할 수 있고 카드 정보가 한 열로 배치되는지도 확인합니다.

브라우저별 수동 확인과 자동화된 정상 판정 기준은 **확인 필요**입니다.

## 알려진 제한과 확인 필요 항목

- 화면에 표시된 스터디와 인원은 `index.html`에 작성된 예시 데이터이며 실제 모집 정보가 아닙니다.
- 페이지는 정적 HTML/CSS/JavaScript로 구성되어 있어 데이터 저장, 인증, 서버 API 동작을 제공하지 않습니다.
- 메뉴 링크는 페이지 안의 위치로 이동합니다. 별도 소개·로그인·스터디 상세 페이지는 확인되지 않았습니다.
- 운영 배포 방식, 지원 브라우저 범위, 실제 스터디 데이터 출처 및 자동 검증 절차는 **확인 필요**입니다.
